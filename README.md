# Safe Harbours

Website for **Safe Harbours Family Treatment Homes**, an Ontario treatment foster care agency —
migrated from WordPress to [Astro 6](https://astro.build) and hosted on **Cloudflare Workers**.

The site lives in [`web/`](./web). It's a mostly-static, prerendered site with one on-demand
endpoint (the contact form) that runs as a Cloudflare Worker.

## Develop

```bash
cd web
npm install --ignore-scripts   # sharp's native build is skipped; not needed (passthrough images)
npm run dev
```

## Build & preview

```bash
cd web
npm run build
npx wrangler dev --config dist/server/wrangler.json   # serve the built Worker locally
```

## Deploy

Pushing to the default branch triggers `.github/workflows/deploy.yml`, which builds and runs
`wrangler deploy` to the `safe-harbours-web` Worker.

**Required GitHub Actions config** (Settings → Secrets and variables → Actions):
- Secrets: `CLOUDFLARE_API_TOKEN` (Workers Scripts:Edit scope), `CLOUDFLARE_ACCOUNT_ID`
- Variable: `PUBLIC_TURNSTILE_SITE_KEY`

**Worker secrets** (set with `wrangler secret put … --config dist/server/wrangler.json`):
`RESEND_TOKEN`, `TURNSTILE_SECRET_KEY`, and optionally `CONTACT_TO` / `CONTACT_FROM`.

## Images

Responsive image variants in `web/public/images/` are generated by `web/scripts/images.mjs`
from `web/scripts/image-manifest.json`:

```bash
cd web && node scripts/images.mjs            # all entries
cd web && node scripts/images.mjs hero logo  # only matching bases
```
